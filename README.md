# Ricardo Tsao

Embedded Systems · Firmware · Control Systems · Robotics · Linux

I work on system-level engineering problems spanning embedded software, firmware, hardware/software integration, control systems, and real-world system validation.

My interests are focused on understanding how systems behave from specification and architecture down to software, hardware, timing, sensing, actuation, and executable implementation.

## Current Focus

* Embedded systems and firmware architecture
* Control systems and robotics
* Motor control and real-time control
* Linux and real-time Linux
* MCU-based system development
* Hardware/software integration and bring-up
* System modeling, verification, and debugging
* Specification-to-executable engineering
