# Historical Projects

This is the canonical index of older public repositories and experiments. It keeps the
profile README and the engineering journey free of platform and project inventories.

Descriptions distinguish original work, ports, derived work, and experiments where
relevant. Everything listed here is preserved as-is and is not under active
development; see the [profile README](../README.md) for current projects.

## Flight Control & Autonomous Systems

### [TMR-FC — Top Multi-Rotor Flight Controller](https://github.com/cctsao1008/tmr-flight-controller)

**2013 · Historical Project**

Historical open hardware and software multirotor flight-controller platform built around STM32F405/STM32F407 and PX4-derived firmware. The platform integrates inertial and environmental sensing, actuator interfaces, data logging, navigation interfaces, and Raspberry Pi companion-computer experiments for OpenCV, ROS, MAVLink, vision, and optical-flow applications.

### [TMR-FC NuttX](https://github.com/cctsao1008/tmrfc-nuttx)

**2013 · Historical Platform Work**

NuttX-based platform work associated with TMR-FC.

### [Bootloader](https://github.com/cctsao1008/Bootloader)

**2013 · Historical Derived Work**

Modified PX4 bootloader for TMR-FC.

### [NTUT Rover](https://github.com/cctsao1008/ntut_rover)

**2014 · Historical Project**

Raspberry Pi-based autonomous rover following recorded GPS waypoints.

## Robotics & Automation

### [Mecanum AGV Motion Control](https://github.com/cctsao1008/mecanum-agv-motion-control)

**2016 · Historical Project**

Vehicle-frame motion control, Mecanum-wheel kinematics, feedback control, simulation, and embedded execution for an AGV mobile base. This repository represents the mobile-base control subsystem rather than an entire robotic system.

### [Instrument Automation Control](https://github.com/cctsao1008/instrument-automation-control)

**2017 · Historical Project**

Legacy Windows-based C/C++ instrument automation and equipment-orchestration software coordinating heterogeneous devices, communication interfaces, scripting, scheduling, and data services in a multi-stage automated workflow.
