# 2006 Quadcopter Project

## Overview

An early embedded control project focused on the design, implementation, and flight control of a quadcopter using an EM78569-based platform.

The project is part of the earliest stage of the engineering journey documented in this profile, combining embedded implementation, real-world sensing and actuation, timing, and closed-loop control.

## Competition Result

- **Award:** 1st Place
- **Competition:** 9th ELAN Microcontroller Application and Artificial Intelligence Design Competition
- **Division:** Microcontroller Application Project / Innovation Division
- **Project:** *Design, Implementation, and Flight Control of a Quadcopter*
- **Institution:** Hsiuping Institute of Technology
- **Students:** Cheng (Ricardo) Tsao, Shin-Chi Tsai
- **Advisor:** Chi-Ching Yang

The English project title above is a translation of the published Chinese title, *四旋翼直升機的設計製作與飛行控制實現*.

## Historical Significance

This project predates the later flight-controller, robotics, autonomous-system, and heterogeneous embedded work documented elsewhere in the profile. Its importance here is not only the competition result, but that it represents an early convergence of embedded software, physical-system behavior, control, timing, and system integration.
